# 読了表 小説 新・人間革命

全30巻・122章を一章ずつ記録していく読了表アプリです。

## できること
- 章名をタップして読了を記録（読んだ日も残ります）
- 進捗率、続けて読んだ日数、読書カレンダー、バッジ
- 創立100周年（2030年11月18日）に向けた目標ペースの表示
- 各章の 📝 から、心に響いた言葉のメモやページの写真を残せます
- 「メモ帳」タブで、残したメモを一覧・検索して読み返せます

## データの保存について
記録・メモ・写真は、それぞれの人のスマホ／パソコンのブラウザの中に保存されます。
サーバーには送られないので、友人同士で共有しても他の人の記録は見えません。
機種変更の前などは「バックアップを保存」でファイルに残してください。

## スマホのホーム画面に追加する
- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：右上のメニュー →「ホーム画面に追加」
